# 🔬 3_ux_research: User Experience & Design Artifacts

This directory houses the human-centered design deliverables, research findings, task models, and usability evaluation scripts created for **NEWM-N450 (Usability & Design / UX Research)**.

---

## 📁 Included Deliverables

| File | Description |
| :--- | :--- |
| **`Research Deliverable_User Research_Kemp.pdf`** | Needfinding interview scripts, demographic breakdowns, qualitative results, and user persona (*Sara L., 38*). |
| **`Analysis Deliverable.pdf`** | Hierarchical Task Analysis (HTA) mapping user friction points during event discovery. |
| **`Design_and_Prototype_Kemp.pdf`** | UML Activity diagrams and initial low-fidelity Marvel interactive wireframe specs. |
| **`Evaluation_Kemp.pdf`** | In-person usability testing scripts, task scenario logs, quantitative survey results, and iteration roadmap. |
| **`HTA for Analysis Deliverable.drawio.png`** | High-resolution HTA visual diagram. |

---

## 📊 Key UX Research Outcomes

* **Validated Usability Metrics:** `4.7 / 5` Ease of Use, `5.0 / 5` Navigation Confidence, `5.0 / 5` Filter Utility.
* **Core Design Shift:** Iterated low-fidelity prototypes into high-fidelity layouts based on direct user feedback regarding header visibility, explicit location formatting, and search scalability.
